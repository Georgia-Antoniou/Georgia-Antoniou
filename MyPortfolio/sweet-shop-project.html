Web Application

Manual QA Tester

On the Sweet Shop project, an intentionally broken web application, I performed comprehensive exploratory and manual testing to identify and document defects. My primary focus was to evaluate the site's functionality from an end-user perspective, with particular attention given to the payment processing functionality. This experience allowed me to practice my skills in discovering common real-world web application issues, including those related to forms, e-commerce transactions, and user flow.

My Responsibilities:

  • Conducted in-depth manual and exploratory testing across the Sweet Shop web application to uncover pre-existing bugs and usability issues.
  • Focused testing efforts on the payment processing and e-commerce functionalities, identifying critical defects in the checkout flow.
  • Documented bugs and provided clear, concise reports detailing the nature of the issue, steps to reproduce, and expected versus actual results.
  • Analyzed the web application from a user's perspective, providing feedback on inconsistencies and areas for improvement in the user interface and user experience.
